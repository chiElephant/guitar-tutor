# Lessons

Lessons are grouped into three grades, each a directory of Markdown files named `<module>-<order>-<slug>.md` (see `FORMAT.md` for the front matter and the `chords`, `alphatex` and `fretboard` blocks). Grade 1 is complete: nine modules that take a beginner from tuning and posture through the eight open chords (Em Am D A E G C Dm), one-minute changes, down-strums and D DU UDU, the capo, E5/A5 power chords, a first riff and a first melody, ending in a checkpoint of three songs at 60 bpm. Grades 2 and 3 currently have an outline (`00-0-overview.md`) plus one worked lesson each; the remaining lessons follow the outline. Each lesson declares `skills:` ids that the practice log tracks, so reuse an existing id when a new lesson practises the same thing. Only public-domain tunes from `content/tabs/` are named as repertoire. All lesson text here is original and licensed CC BY-SA 4.0 (see `../LICENSE`).
