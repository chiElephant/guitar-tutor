D minor is the sad twin of D major. One finger moves, and the mood changes completely. With Dm you have all eight open chords of Grade 1: Em Am D A E G C Dm.

```chords
Dm D
```

## Placing the fingers

1. **First finger** on string 1 (high e) at fret 1.
2. **Second finger** on string 3 (G) at fret 2.
3. **Third finger** on string 2 (B) at fret 3.
4. String 4 (D) open. Strum from string 4; skip strings 6 and 5.

Compare the boxes above. In D major, string 1 is at fret 2; in D minor it drops to fret 1. The first finger takes over that string, and the other two fingers swap roles. Because the whole hand shape rotates, it is easier to think of Dm as its own chord rather than "D with a change".

```alphatex
\ts 4 4 (1.1 3.2 2.3 0.4).4 (1.1 3.2 2.3 0.4).4 (1.1 3.2 2.3 0.4).4 (1.1 3.2 2.3 0.4).4 | (0.1 1.2 2.3 2.4 0.5).4 (0.1 1.2 2.3 2.4 0.5).4 (0.1 1.2 2.3 2.4 0.5).4 (0.1 1.2 2.3 2.4 0.5).4 |
```

## Useful changes

- **Dm to Am**: finger 2 stays at fret 2 but moves from string 3 to string 4; finger 1 moves from string 1 to string 2, staying at fret 1; finger 3 goes from string 2 fret 3 to string 3 fret 2.
- **Dm to C**: finger 1 goes to string 2 fret 1; finger 2 to string 4 fret 2; finger 3 to string 5 fret 3. All three fingers climb one string towards the ceiling and the shape widens.

## A two-chord tune

Shady Grove is a modal American song that sits happily on just Dm and C: **Dm | C | Dm | C | Dm | C | Dm | Dm**. Listen to [Play Shady Grove](piece:shady-grove) and strum along with one chord per bar.

## Practice

- Place Dm, pick strings 4 to 1 to check, repeat ten times.
- One-minute changes Dm to Am and Dm to C.
- Shady Grove on Dm and C, four down-strums per bar, 60 bpm.
